# 🌾 A Importância do Agro

Projeto desenvolvido em HTML, CSS e JavaScript com foco em acessibilidade para pessoas com baixa visão.

## Objetivo
Destacar a importância do agronegócio para a alimentação, economia, geração de empregos e sustentabilidade.

## Recursos
- Interface responsiva
- Paleta de cores vermelha
- Texto com alto contraste
- Botão para aumentar e diminuir fonte
- Modo de alto contraste
- Navegação acessível

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## Como Executar
1. Salve o código em um arquivo `index.html`.
2. Abra o arquivo em qualquer navegador moderno.

## Tema
O agro é essencial para o desenvolvimento do país, fornecendo alimentos, empregos e contribuindo para a economia e a sustentabilidade.
